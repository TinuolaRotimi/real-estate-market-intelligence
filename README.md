# Real Estate Market Intelligence Tool

Real estate market intelligence platform for investment decision support. Built on the Melbourne Housing dataset with Python, Pandas, Scikit-learn, Plotly, and Flask.

## Overview

Analyzed over 34,000 real property transactions across 300+ Melbourne suburbs. Engineered an Automated Valuation Model using Random Forest regression and created a suburb investment scoring framework to identify prime investment opportunities. Delivered an executive dashboard with geospatial price mapping and investment tier classification.

## Results

| Metric | Value |
|--------|-------|
| Properties Analyzed | 34,857 |
| Suburbs Covered | 300+ |

| Suburb Investment Tiers | Prime, Growth, Value, Speculative |

## Features

- 34,857 real property transactions from the Melbourne Housing dataset
- Automated Valuation Model with Random Forest regression
- Feature importance analysis for price drivers
- Suburb investment scoring with 5-factor weighted composite
- Correlation matrix heatmap of property features
- 4-panel executive dashboard with dark theme
- Interactive Plotly mapbox geospatial visualization
- Flask web application with suburb lookup
